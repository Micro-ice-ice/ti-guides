# Библиотека ассетов

Ассеты сгруппированы по типу компонента, а не по конкретному гайду. Благодаря этому общую технологию или улучшение юнита можно подключать из любого гайда без копирования файла.

## Структура

- `technologies/common` — общие технологии; языковая версия указывается суффиксом `-ru`.
- `technologies/unit-upgrades` — общие улучшения юнитов.
- `technologies/faction/<faction>` — фракционные технологии и уникальные улучшения юнитов.
- `breakthroughs/<faction>` — карты прорыва.
- `factions/<faction>` — остальные компоненты фракции: лидеры, юниты, памятки, домашние системы и записки.

Каждый файл должен содержать ровно одну карточку. Имена файлов пишутся в нижнем регистре через дефис; для локализованных вариантов используется суффикс языка, например `gravity-drive-ru.jpg`.

## Подключение из гайда

Пути считаются относительно каталога `factions`. Например:

```html
<img src="assets/technologies/common/gravity-drive-ru.jpg" alt="Гравитационный двигатель">
```
